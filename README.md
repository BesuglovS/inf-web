# Информатика 7–9 классы

Учебный сайт по информатике для 7–9 классов на основе Федеральной рабочей программы основного общего образования (базовый уровень). Содержит теоретические материалы с интерактивными калькуляторами, квизами и инструментами для изучения ключевых концепций информатики.

## Разделы

## Технологии

- **HTML5** — структура страниц
- **CSS3** — стилизация, адаптивный дизайн, переключение тем
- **JavaScript** — интерактивные инструменты, квизы
- **Service Worker** — PWA, офлайн-кэширование
- **JSON-LD** — структурированные данные для SEO

## Запуск

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Особенности

- **Интерактивные калькуляторы** — конвертер единиц информации (бит/байт/КБ/МБ/ГБ), расчёт объёма текста, RGB-калькулятор
- **Квизы** — тестирование знаний по каждой теме
- **Тёмная/светлая тема** — автоматическое переключение по настройкам системы
- **Прогресс-бар** — отслеживание изученных тем
- **PWA / Офлайн** — сайт работает без интернета после первого посещения
- **SEO** — JSON-LD структурированные данные, Open Graph, sitemap
- **Адаптивный дизайн** — корректное отображение на мобильных устройствах
