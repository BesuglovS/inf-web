# Основы информационных технологий — видеокурс «От абака до микросхемы»

Статический сайт-курс: к каждому видео — страница с плеером и разбором темы
(конспект, термины, вопросы для самопроверки, мини-практика). Без сборки и бандлеров.

Прод: `https://inf.nayanovaacademy.ru` (nginx, `root /var/www/inf.nayanovaacademy.ru/public`).

## Структура

```
index.html            # лендинг: превью курса, ось времени, список занятий, «как заниматься»
urok-NN.html          # страница занятия, NN = номер эпизода курса
proekt-simpletron.html # проект к занятию 07: Simpletron и загрузка из файла
proekt-simple-compiler.html # проект к занятию 08: компилятор Simple в SML
css/styles.css        # единственный файл стилей (токены в :root)
js/player.js          # плеер YouTube по клику (только для занятий без локального файла)
js/interactive.js     # карточки терминов и квиз с проверкой ответов
media/intro.mp4       # два вступительных ролика подряд (4:02, локально)
media/intro-poster.jpg
media/lessons/        # превью занятий — кадры из первого интро
media/yt/             # превью Crash Course Computer Science
favicon.svg
data/vk-videos.json   # соответствие уроков и роликов ВК
docs/                 # официальные документы (в репозиторий не входят)
```

## Видео в ВК

На страницах занятий видео встроено из ВК (`vk.com/video_ext.php`), список роликов —
из плейлиста [«Основы информационных технологий»](https://vkvideo.ru/playlist/-196622247_1).
Рядом с плеером есть ссылка на оригинальный выпуск Crash Course на YouTube.

Порядок в плейлисте: два первых ролика — превью (в картинках и словами), дальше уроки 01—40 по порядку.
Соответствие «номер урока → id ролика» хранится в `data/vk-videos.json`.

На главной два превью играются локально одним файлом `media/intro.mp4`
(склейка `000.mp4` + `00.mp4`, 4:02). Остальные локальные копии уроков (6,2 ГБ)
лежат вне проекта — в `_media/inf-web-mp4` рядом с каталогом сайтов — и в деплой не попадают.


## Как добавить занятие

1. Взять id ролика из плейлиста ВК и добавить его в `data/vk-videos.json`
   под номером урока (два первых ролика плейлиста — превью).
2. Скопировать любую готовую страницу `urok-NN.html` и поменять:
   - `<title>`, `meta description`, номер и заголовок в `.lesson-head`;
   - путь к видео и постеру в `.video`;
   - разделы `.chapter` (якоря `ch-1…ch-5` должны совпадать с оглавлением `.toc`);
   - блок `.pager` (предыдущее/следующее занятие).
3. Добавить карточку в список `.lessons` на `index.html` и обновить счётчик в `.section__head`.

## Интерактив и схемы на страницах занятий

Каждая страница 03—40 содержит:

- **Схему** — оригинальный SVG под тему занятия (веса разрядов, полусумматор, конвейер компиляции,
  граница классов и т. д.). Рисунки нарисованы с нуля под этот проект, это не кадры из видео,
  поэтому вопросов с правами не возникает.
- **Модель** (на четырёх страницах) — интерактивный стенд по содержанию урока:
  логические операции на транзисторных схемах NOT, AND, OR и XOR (03), восьмибитное число
  с переводом в десятичную и шестнадцатеричную запись (04), четырёхбитный сумматор
  с флагом переполнения (05), групповое кодирование строки (21). Строки таблиц истинности
  на странице 03 переключают схему в выбранное состояние.
- **Интерактивные схемы** на странице 02 — переключение напряжения на сетке лампы
  и тока базы транзистора.
- **Карточки терминов** — кнопка с термином, после нажатия раскрывается определение
  (`aria-pressed` переключается, повторное нажатие закрывает).
- **Квиз** — четыре вопроса с одним верным вариантом. Ответ проверяется сразу, показывается
  пояснение, правильный вариант подсвечивается; счётчик и полоса прогресса обновляются.
  Выбор сохраняется в `localStorage` под ключом `inf-web-quiz` (объект «ключ занятия → ответы»),
  поэтому после перезагрузки результат на месте. Кнопка «Пройти заново» очищает только это занятие.
- **Проект к занятию 07** — `proekt-simpletron.html`: симулятор Simpletron на Python, система
  команд SML и загрузка программы из файла. Заготовки без классов, тестовые стенограммы и критерии.
- **Проект к занятию 08** — `proekt-simple-compiler.html`: компилятор учебного языка Simple в SML,
  два прохода, таблица символов, выражения и переходы; опирается на симулятор из занятия 07.

Логика — `js/interactive.js` (без зависимостей). Стили — блоки «Схемы и модели» и «Интерактив»
в `css/styles.css`; в печатной версии скрыты кнопки и статусы, а схемы и таблицы остаются.

## Локальный запуск

```powershell
cd G:\WebSites\na\inf-web
python -m http.server 8000
# http://localhost:8000
```

`file://` не подойдёт: страницы ссылаются на `css/`, `js/`, `favicon.svg` и видео
относительными путями.

## Требования

- Тексты разборов — собственные конспекты тем, не расшифровки видео.
- Ссылки на YouTube (если используются) — только `data-video` из 11 символов, сверять с
  [плейлистом](https://www.youtube.com/playlist?list=PL8dPuuaLjXtNlUrzyH5r6jN9ulIgZBpdo).
- Доступность: `lang="ru"`, skip-link, `:focus-visible`, `prefers-reduced-motion`, печатная версия.
