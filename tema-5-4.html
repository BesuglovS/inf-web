Проверка делимости

В Python проверка делимости выполняется с помощью оператора % (остаток от деления). Если a % b == 0, то a делится на b без остатка.

n = int(input())
if n % 2 == 0:
    print('Чётное')
else:
    print('Нечётное')

Проверка на простоту:

Натуральное число называется простым, если оно имеет ровно два делителя: 1 и само себя.

n = int(input())
is_prime = True
for i in range(2, int(n**0.5) + 1):
    if n % i == 0:
        is_prime = False
        break
print('Простое' if is_prime else 'Составное')

Поиск максимума и минимума

# Поиск максимума из N чисел
max_val = int(input())
for i in range(4):
    x = int(input())
    if x > max_val:
        max_val = x
print('Максимум:', max_val)

Для поиска минимума замените > на <.

Вычисление суммы последовательности

n = int(input('Сколько чисел? '))
s = 0
for i in range(n):
    x = int(input())
    s += x
print('Сумма:', s)

Сумма цифр числа:

n = int(input())
s = 0
while n > 0:
    s += n % 10
    n //= 10
print('Сумма цифр:', s)

Выделение цифр числа

Для выделения цифр числа используются операции % (остаток) и // (целочисленное деление).

n = 12345
while n > 0:
    digit = n % 10   # последняя цифра
    print(digit, end=' ')
    n = n // 10        # отбрасываем последнюю цифру
# Вывод: 5 4 3 2 1
Обратный порядок: Чтобы получить цифры в прямом порядке, можно сохранить их в список и перевернуть.
