# Руководство по участию в разработке (Contributing Guide)

Спасибо за интерес к проекту **inf-web**! Мы приветствуем любой вклад: исправление ошибок, улучшение документации, добавление новых функций и тестов.

## Как начать

1. **Форкните репозиторий** и клонируйте его локально.
2. **Установите зависимости** (если есть): `npm install`
3. **Создайте ветку** для ваших изменений: `git checkout -b feature/моя-фича`
4. **Внесите изменения** и проверьте их локально.
5. **Запустите тесты**: `npx vitest run`
6. **Создайте Pull Request** с описанием ваших изменений.

## Стиль кода

- **JavaScript**: Используйте ES6+ синтаксис. Функции должны быть чистыми где это возможно.
- **Именование**: camelCase для переменных и функций, kebab-case для файлов.
- **Комментарии**: Пишите по-русски, объясняйте сложную логику.
- **HTML**: Семантическая вёрстка, поддерживайте доступность (a11y).
- **CSS**: Используйте CSS-переменные для цветов и размеров.

## Добавление новых калькуляторов

1. Создайте функцию в соответствующем модуле (`js/lib/calculators.js` или `js/lib/conversion.js`).
2. Добавьте HTML-разметку калькулятора на нужную страницу (тему).
3. Инициализируйте обработчики событий в `js/lib/main.js`.
4. Добавьте unit-тесты в `tests/calculators.test.js` или `tests/dom.test.js`.
5. Обновите `data/topics.json` если добавляете новую тему.

## Добавление вопросов для квизов

1. Откройте `data/quizzes.json`.
2. Добавьте новый раздел под соответствующим ключом темы.
3. Каждый вопрос должен содержать:
   - `q`: текст вопроса
   - `options`: массив из 3 вариантов ответа
   - `answer`: индекс правильного ответа (0, 1 или 2)
   - `explanation`: пояснение к правильному ответу

Пример:
```json
{
  "q": "Сколько бит в одном байте?",
  "options": ["4", "8", "16"],
  "answer": 1,
  "explanation": "Один байт равен 8 битам."
}
```

## Запуск тестов

```bash
# Запуск всех тестов
npx vitest run

# Запуск в режиме наблюдения
npx vitest

# Запуск конкретного файла
npx vitest run tests/calculators.test.js

# С покрытием кода
npx vitest run --coverage
```

## Сборка и деплой

Проект не требует сборки — это статический сайт. Все файлы HTML, CSS и JS загружаются напрямую браузером. Для деплоя используйте:

```powershell
.\deploy.ps1
```
