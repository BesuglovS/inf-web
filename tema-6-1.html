6.1. Моделирование и формализация

Понятие модели

Модель — это упрощённое представление реального объекта, процесса или явления, которое сохраняет его существенные свойства.

Моделирование — процесс построения и исследования моделей для изучения реальных объектов.

Виды моделей по способу представления:

ТипОписаниеПримеры
Материальные (предметные)Воспроизводят геометрические и физические свойстваГлобус, макет здания, скелет
Информационные (знаковые)Описывают объект с помощью знаков и символовФормулы, таблицы, графики, схемы
Важно: Модель не является точной копией объекта — она отражает только те свойства, которые важны для цели моделирования.

Этапы моделирования

  1. Постановка задачи — определение цели моделирования
  2. Разработка модели — выделение существенных свойств, формализация
  3. Компьютерный эксперимент — реализация модели на компьютере
  4. Анализ результатов — проверка адекватности модели, корректировка
Формализация — замена реального объекта его формальным описанием (с помощью формул, таблиц, схем и т.д.).

Классификация моделей

По области использования:

  • Учебные — наглядные пособия, тренажёры
  • Научные — модели физических, химических процессов
  • Игровые — компьютерные игры, экономические игры
  • Имитационные — моделирование поведения сложных систем

По фактору времени:

  • Статические — описывают состояние объекта в данный момент
  • Динамические — описывают изменение объекта во времени

Табличные модели

Табличная модель — представление информации в виде таблицы, где строки соответствуют объектам, а столбцы — их свойствам.

Виды таблиц:

  • Таблица «объект-свойство» — в строках объекты, в столбцах свойства (например, страны: название, столица, население)
  • Таблица «объект-объект» — отражает связи между объектами (например, таблица расстояний между городами)

Пример таблицы «объект-свойство»:

ГородСтолицаНаселение (млн)Площадь (км²)
МоскваРоссия12,62 561
ТокиоЯпония13,92 194
ПекинКитай21,516 410

Пример таблицы «объект-объект» (расстояния):

МоскваС-ПетербургКазань
Москва0700820
С-Петербург70001 500
Казань8201 5000
Достоинства табличных моделей: наглядность, структурированность, возможность автоматической обработки.

Математические модели

Математическая модель — описание объекта с помощью математических формул и уравнений.

Примеры математических моделей:

ЗадачаМодельФормула
Площадь кругаГеометрическаяS = π × r²
Движение телаФизическаяS = v × t + (a × t²) / 2
Банковский вкладЭкономическаяS = P × (1 + r)ⁿ
Рост популяцииБиологическаяN = N₀ × eᵏᵗ

Пример: расчёт стоимости кредита

Модель аннуитетного платежа:

П = К × (r × (1+r)ⁿ) / ((1+r)ⁿ − 1)

где К — сумма кредита, r — месячная ставка, n — количество месяцев.

Пример: модель «хищник — жертва»

# Модель Лотки-Вольтерры
# x — число жертв, y — число хищников
dx/dt = a*x - b*x*y    # рост жертв, вымирание от хищников
dy/dt = c*x*y - d*y     # рост хищников, вымирание без пищи

Эта модель описывает циклические колебания популяций в экосистеме.

Практические задания

Задание 1. Классификация моделей

Определите тип каждой модели:

  1. Глобус Земли → _____
  2. Формула площади треугольника → _____
  3. Схема метро → _____
  4. Компьютерная игра «Симулятор города» → _____
  1. Материальная (предметная)
  2. Информационная (знаковая), математическая
  3. Информационная (знаковая), графическая
  4. Имитационная, компьютерная

Задание 2. Построение табличной модели

Составьте таблицу «объект-свойство» для 3 школьных предметов (название, количество часов в неделю, форма контроля).

ПредметЧасы/неделюКонтроль
Математика5Домашние работы, контрольные
Русский язык3Диктанты, изложения
Информатика2Тесты, практикумы

Задание 3. Этапы моделирования

Задача: спрогнозировать количество учеников в школе через 5 лет. Опишите каждый этап моделирования.

  1. Постановка задачи: определить число учеников через 5 лет
  2. Разработка модели: анализ статистики за предыдущие годы, выявление тренда, построение формулы (линейная или полиномиальная экстраполяция)
  3. Компьютерный эксперимент: реализация в электронной таблице, подстановка данных
  4. Анализ результатов: сравнение прогноза с фактическими данными, корректировка модели
