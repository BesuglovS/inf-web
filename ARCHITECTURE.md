# Архитектура проекта inf-web

## Обзор

Статический образовательный сайт по информатике для 7–9 классов. Содержит 22 тематические страницы, интерактивные калькуляторы, квизы и Service Worker для офлайн-доступа. Основан на Федеральной рабочей программе (базовый уровень).

## Структура проекта

```
inf-web/
├── index.html                 # Главная (выбор класса, JSON-LD Course)
├── 7-klass.html               # Обзор 7 класса
├── 8-klass.html               # Обзор 8 класса
├── 9-klass.html               # Обзор 9 класса
├── tema-{1-9}-{n}.html        # 22 тематические страницы
├── 404.html                   # Страница ошибки
├── css/
│   └── styles.css             # Единый CSS-файл
├── js/
│   ├── scripts.js             # Интерактивные инструменты (929 строк)
│   └── quiz.js                # Система квизов
├── sw.js                      # Service Worker (кэширование)
├── docs/                      # Документы ФРП (PDF)
│   ├── 7/                     # Документы для 7 класса
│   ├── 8/                     # Документы для 8 класса
│   └── 9/                     # Документы для 9 класса
├── data/                      # Данные (пусто)
├── sitemap.xml                # Карта сайта
├── robots.txt                 # Директивы для поисковиков
└── deploy.ps1                 # Деплой
```

## Архитектура приложения

### Клиентская архитектура

Приложение полностью статическое — серверная логика отсутствует. Вся интерактивность реализована на клиенте.

```
index.html
├── css/styles.css             # Стили
├── js/scripts.js              # Интерактивные инструменты
│   ├── Конвертер единиц       # бит/байт/КБ/МБ/ГБ
│   ├── Калькулятор объёма     # Расчёт информационного объёма текста
│   ├── RGB-калькулятор        # Цветовая модель с hex-выходом
│   └── Тематические упражнения
└── js/quiz.js                 # Квиз-система
```

### Навигация

```
index.html (выбор класса)
├── 7-klass.html (3 раздела, 12 тем)
│   ├── tema-1-1.html ... tema-1-3.html  (Цифровая грамотность)
│   ├── tema-2-1.html ... tema-2-2.html  (Теоретические основы)
│   └── tema-3-1.html ... tema-3-3.html  (Теоретические основы)
├── 8-klass.html (2 раздела, 6 тем)
│   ├── tema-4-1.html ... tema-4-2.html  (Математические основы)
│   └── tema-5-1.html ... tema-5-4.html  (Алгоритмизация)
└── 9-klass.html (4 раздела, 4 темы)
    └── tema-{6-9}-{n}.html              (Различные разделы)
```

### Интерактивные инструменты (scripts.js)

| Инструмент | Назначение |
|------------|------------|
| Конвертер единиц | Перевод между битами, байтами, КБ, МБ, ГБ |
| Калькулятор объёма | Расчёт информационного объёма текста (UTF-8/Unicode) |
| RGB-калькулятор | Определение цвета по RGB-компонентам с hex-выходом |
| Квизы | Тестирование знаний по каждой теме |

### Service Worker (sw.js)

- **Кэширование** всех HTML-страниц и статических ресурсов
- **Версионирование** кэша (`inf-web-v2`)
- **Стратегия** cache-first для статики, network-first для навигации
- **Офлайн-режим** — полная работа без интернета

### Хранение данных

| Ключ | Назначение |
|------|-----------|
| `inf-web-progress` | Пройденные темы (объект с темами) |
| `inf-web-theme` | Предпочтения темы (светлая/тёмная) |

## Дизайн-система

Общая с другими проектами экосистемы:

- Фон: тёмный градиент (`#0f0c29` → `#302b63` → `#24243e`)
- Акцент: фиолетовый градиент (`#667eea` → `#764ba2`)
- Карточки: полупрозрачные с бордерами
- Шрифт: системный стек

## Документы ФРП

Папка `docs/` содержит официальные документы:

- Федеральная рабочая программа (базовый и углублённый уровни)
- Образовательные стандарты (ФГОС)
- Приказы Минпросвещения

Эти документы служат авторитетным источником для структуры контента.

## Деплой

```bash
./deploy.ps1
```

Статический деплой — копирование HTML/CSS/JS файлов на веб-сервер.

## Ограничения

- Нет серверной логики
- Нет системы сборки
- Данные квизов захардкожены в JS
- Нет тестов
