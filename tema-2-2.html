Алфавит и кодирование

Алфавит — это конечный набор символов (знаков), используемых для представления информации.

Мощность алфавита (N) — количество символов в алфавите.

Кодирование — это преобразование информации из одной формы представления в другую.

Примеры алфавитов:

АлфавитСимволыМощность
РусскийА, Б, ..., Я (33 буквы)33
ЛатинскийA, B, ..., Z (26 букв)26
Десятичный0, 1, 2, ..., 910
Двоичный0, 12
Важно: Чем больше мощность алфавита, тем больше информации несёт один символ.

Двоичное кодирование

Компьютер использует двоичный алфавит, состоящий всего из двух символов: 0 и 1.

Каждый символ двоичного алфавита называется бит (от англ. binary digit — двоичная цифра).

Почему именно двоичное кодирование?

  • Два состояния легко реализовать технически: есть ток / нет тока, намагничено / не намагничено
  • Надёжность — два состояния легко различить
  • Простота вычислений — двоичная арифметика проще десятичной

Двоичная система счисления

Любое число можно представить в двоичном виде. Каждая позиция (разряд) — это степень числа 2:

Степень2⁷2⁶2⁵2⁴2³2²2¹2⁰
Значение1286432168421
Пример: Число 13₁₀ = 1101₂ (1×8 + 1×4 + 0×2 + 1×1 = 8 + 4 + 0 + 1 = 13)

Кодирование текстовой информации

Для кодирования текста каждому символу алфавита ставится в соответствие уникальный двоичный код.

Таблицы кодировки:

КодировкаРазмерОсобенности
ASCII7 бит (128 символов)Латинские буквы, цифры, знаки. Базовая кодировка.
Windows-12518 бит (256 символов)Поддерживает русские буквы.
Unicode (UTF-8)Переменная (1–4 байта)Стандарт, поддерживающий все языки мира. Самая распространённая кодировка в Интернете.
Unicode (UTF-16)2 или 4 байтаИспользуется в Windows и Java.
Интересно: В кодировке ASCII буква 'A' имеет код 65₁₀ = 01000001₂, буква 'a' — 97₁₀ = 01100001₂. Разница — 32, что равно 2⁵.

Кодирование графической информации

Изображение на экране состоит из пикселей (picture element) — минимальных точек изображения.

Основные характеристики:

  • Разрешение — количество пикселей по ширине и высоте (например, 1920×1080)
  • Глубина цвета — количество бит, отводимых на кодирование цвета одного пикселя
  • Цветовая модель RGB — каждый цвет образуется смешением трёх базовых цветов: Red, Green, Blue

Цветовые режимы:

Глубина цветаКоличество цветовОписание
1 бит2Чёрно-белое изображение
8 бит256Индексированные цвета
16 бит65 536High Color
24 бита16 777 216True Color (8 бит на канал RGB)
32 бита16 777 216 + альфа-каналTrue Color с прозрачностью
Формула объёма изображения:
V = Ширина × Высота × Глубина цвета (бит)
