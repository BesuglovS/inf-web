Понятие электронной таблицы

Электронная таблица (ЭТ) — это программа для обработки и визуализации числовых данных, организованных в виде таблицы.

Примеры: Microsoft Excel, Google Sheets, LibreOffice Calc.

Основное назначение: автоматизация вычислений, анализ данных, построение диаграмм, численное моделирование.

СтрокаНумеруется числами (1, 2, 3, ...)

Важно: Формула всегда начинается со знака «=». В формуле можно использовать числа, ссылки на ячейки, функции и операторы.

Адресация ячеек

Относительная адресация

A1 — при копировании формулы адрес изменяется относительно нового положения.

Пример: Если в ячейке C1 записана формула =A1+B1, то при копировании в C2 получим =A2+B2.

Абсолютная адресация

$A$1 — при копировании адрес не изменяется.

Пример: Формула =A1*$B$1 при копировании сохранит ссылку на B1.

Смешанная адресация

$A1 — фиксирован столбец, A$1 — фиксирована строка.

A1ОтносительныйОтносительная
$A$1АбсолютныйАбсолютная

Форматирование и условное форматирование

Форматирование ячеек:

ПараметрВозможности
Числовой форматЦелые, дробные, денежные, проценты, даты
ШрифтНазвание, размер, цвет, жирный, курсив, подчёркивание
ВыравниваниеПо горизонтали (влево/по центру/вправо), по вертикали
ГраницыОбводка ячеек линиями
ЗаливкаФоновый цвет ячеек

Условное форматирование:

Автоматическое изменение внешнего вида ячеек в зависимости от значений.

  • Цветовая шкала — градиент цвета от минимального до максимального значения
  • Набор значков — значки (стрелки, флажки, звёзды) в зависимости от условия
  • Правила выделения — выделение ячеек больше/меньше заданного значения

Пример: Выделить красным все оценки «2», зелёным — все «5».

Валидация данных:

Ограничение типа данных, которые можно ввести в ячейку:

  • Только целые числа от 1 до 100
  • Список допустимых значений (выпадающий список)
  • Дата в пределах определённого диапазона
  • Длина текста не более N символов

Практические задания

Задание 1. Адресация

В ячейке D2 записана формула =A1+$B$2*C1. Какая формула будет в D5 после копирования?

=A4+$B$2*C4 — A1→A4 (относительная), $B$2→$B$2 (абсолютная), C1→C4 (относительная).

Задание 2. Типы данных

Определите тип данных для каждого значения:

  1. =СУММ(A1:A10)
  2. 01.03.2024
  3. "Итого по классу"
  4. 3,14159
  1. Формула
  2. Дата/время
  3. Текст
  4. Число (вещественное)

Задание 3. Практическая задача

Составьте таблицу успеваемости 5 учеников (Имя, Математика, Русский, Информатика, Средний балл). Какой формулой вычислить средний балл?

Формула среднего балла: =СРЗНАЧ(B2:D2) или =(B2+C2+D2)/3

Для автоматического заполнения — протяните формулу вниз на остальные строки.
