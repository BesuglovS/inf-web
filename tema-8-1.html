Локальные и глобальные сети

Компьютерная сеть — это два или более компьютеров, соединённых для обмена информацией.

ТипРазмерПример
LAN (локальная)Одно зданиеСеть в школе
WAN (глобальная)МирИнтернет
MAN (городская)ГородГородская сеть

Топологии сетей:

  • Шина — все устройства к одному кабелю
  • Звезда — к центральному коммутатору
  • Кольцо — по кругу

IP-адресация

IP-адрес — уникальный идентификатор устройства в сети.

IPv4: 32 бита, запись: четыре числа от 0 до 255 через точку. Пример: 192.168.1.1

IPv6: 128 бит — новое поколение адресации.

DNS — преобразует доменные имена (yandex.ru) в IP-адреса.

Классы IP-адресов:

КлассДиапазон первого октетаМаска по умолчаниюНазначение
A1–126255.0.0.0Крупные сети
B128–191255.255.0.0Средние сети
C192–223255.255.255.0Малые сети

Частные IP-адреса:

  • 10.0.0.0 – 10.255.255.255
  • 172.16.0.0 – 172.31.255.255
  • 192.168.0.0 – 192.168.255.255

Эти адреса не маршрутизируются в Интернете и используются только в локальных сетях.

Службы Интернета

  • WWW — веб-страницы, сайты
  • E-mail — электронная почта
  • Файлообмен — FTP, торренты
  • Облачные сервисы — удалённое хранение данных
  • Поисковые системы — Яндекс, Google
  • Социальные сети — общение и контент

Веб-технологии

Веб-страница — документ на языке HTML.

Браузер — программа для просмотра (Chrome, Firefox, Edge).

URL — адрес ресурса: протокол://домен/путь

Компоненты веб-страницы:

ТехнологияНазначение
HTMLСтруктура и содержание страницы
CSSОформление и стили
JavaScriptИнтерактивность и логика

Протокол HTTP:

Клиент (браузер) отправляет запрос → Сервер обрабатывает → Возвращает ответ:

  • GET — получить данные (загрузка страницы)
  • POST — отправить данные (форма, загрузка файла)
  • PUT — обновить данные
  • DELETE — удалить данные

Статус-коды HTTP:

404Страница не найдена

Практические задания

Задание 1. Типы сетей

Определите тип сети для каждого случая:

  1. Компьютерный класс в школе
  2. Интернет
  3. Сеть между филиалами банка в одном городе
  1. LAN (локальная сеть)
  2. WAN (глобальная сеть)
  3. MAN (городская сеть)

Задание 2. Протоколы

Какой протокол используется для:

  1. Просмотра веб-страниц
  2. Отправки электронной почты
  3. Скачивания файлов с FTP-сервера
  1. HTTP/HTTPS
  2. SMTP (отправка), POP3/IMAP (получение)
  3. FTP

Задание 3. IP-адресация

Сколько устройств может быть в сети с маской 255.255.255.0 (класс C)?

2⁸ − 2 = 254 устройства (минус адрес сети и.broadcast-адрес).

Задание 4. TCP и UDP

Для каких задач лучше использовать TCP, а для каких — UDP?

  1. Видеозвонок
  2. Отправка файла
  3. Онлайн-игра
  4. Загрузка веб-страницы
  1. UDP (важна скорость, допустимы потери)
  2. TCP (важна надёжность)
  3. UDP (важна скорость)
  4. TCP (важна надёжность)
