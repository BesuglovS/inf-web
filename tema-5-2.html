Знакомство с Python

Python — современный язык программирования общего назначения, который широко используется в науке о данных, веб-разработке, искусственном интеллекте, автоматизации и обучении программированию.

Python — интерпретируемый язык: программа выполняется построчно без предварительной компиляции в машинный код.

Создатель: Гвидо ван Росcум (1956 г.р.) — голландский программист. Язык создан в 1991 году. Название — в честь комедийного шоу «Monty Python's Flying Circus», а не в честь змеи.

Особенности Python:

  • Простой синтаксис — код читается почти как текст на естественном языке
  • Свободное использование — открытый исходный код, бесплатная лицензия
  • Кроссплатформенность — работает на Windows, macOS, Linux
  • Большая стандартная библиотека — множество готовых модулей
  • Динамическая типизация — тип переменной определяется во время выполнения программы

Оператор присваивания

Основная операция — присваивание переменной значения:

имя_переменной = значение_или_выражение

Знак = здесь не означает «равно», а означает «становится равным».

Примеры:

a = 25          # переменной a присваивается значение 25
name = 'Анна'   # переменной name присваивается строка
pi = 3.14       # вещественное число
flag = True     # логическое значение
В Python тип переменной не указывается — он определяется автоматически по значению. Это называется динамическая типизация.

Ввод и вывод данных

Вывод данных: print()

Оператор print() выводит данные на экран:

print('Привет, мир!')      # вывод строки
print('Результат:', 2 + 3) # вывод выражения
print(1, 2, 3)              # несколько значений через пробел

По умолчанию между значениями вставляется пробел. Его можно изменить параметром sep:

print(1, 2, 3, sep='-')    # Результат: 1-2-3
print(1, 2, 3, sep='')     # Результат: 123

Формат вывода

Форматирование позволяет задать количество позиций для выводимого числа:

a = 1/3
b = 1/9
print('{:7.3f} {:7.3f}'.format(a, b))
# Результат:   0.333   0.111

r = 5.4
c = 2 * 3.14 * r
s = 3.14 * r * r
print('Длина окружности c={:6.4f}'.format(c))
print('Площадь круга    s={:6.4f}'.format(s))

Ввод данных: input()

Оператор input() считывает строку с клавиатуры:

name = input('Как тебя зовут? ')
print('Привет, ', name)
Важно: Функция input() всегда возвращает строку (тип str). Чтобы получить число, нужно преобразовать тип:
n = int(input())               # ввод целого числа
x = float(input())             # ввод вещественного числа
n = int(input('Введите n: '))  # ввод с приглашением

Ввод нескольких значений

Для ввода нескольких чисел в одной строке используют функции split() и map():

a, b = map(int, input().split())
# Пользователь вводит: 5 10
# Результат: a = 5, b = 10

💻 Первая программа

Программа вычисляет длину окружности и площадь круга:

pi = 3.14159
r = float(input('Введите радиус: '))
c = 2 * pi * r
s = pi * r * r
print('Длина окружности:', round(c, 2))
print('Площадь круга:', round(s, 2))

Пример ввода: 5.4

Пример вывода:

Длина окружности: 33.93
Площадь круга: 91.61

🧪 Практическое задание

Определите результат выражений без компьютера:

1) 15 // 4   2) 15 % 4   3) 2 ** 10   4) 17 / 5

1) 15 // 4 = 3 — целочисленное деление (полных четвёрок в 15 — три)

2) 15 % 4 = 3 — остаток (15 = 4 × 3 + 3)

3) 2 ** 10 = 1024 — две в десятой степени

4) 17 / 5 = 3.4 — обычное деление (всегда вещественный результат)

Строковый тип данных

Строка — это последовательность символов, заключённая в кавычки:

s1 = 'Привет'        # одинарные кавычки
s2 = "Мир"           # двойные кавычки
s3 = '''Многострочная
строка'''            # тройные кавычки

Индексация: Нумерация символов начинается с 0. Последний символ — с индекса -1. Срез [a:b] возвращает символы с позиции a по (b−1).

Логический тип данных

Величины логического типа принимают два значения: True (истина) и False (ложь).

Логические значения получаются в результате операций сравнения:

ОперацияСмыслПримерРезультат
==Равно5 == 5True
!=Не равно5 != 3True
>Больше5 > 3True
<Меньше5 < 3False
>=Больше или равно5 >= 5True
<=Меньше или равно5 <= 3False

В Python можно записывать двойные неравенства:

x = 5
if 1 < x < 10:
    print('x находится между 1 и 10')
Порядок: False < True. Ложь соответствует 0, Истина — 1.
