Знакомство с Python

Python — современный язык программирования, который широко используется в науке, веб-разработке, анализе данных и обучении программированию.

Python — интерпретируемый язык: программа выполняется сразу без предварительной компиляции.

Создатель: Гвидо ван Россум (1991 г.). Название в честь комедийного шоу «Monty Python's Flying Circus».

Переменные и типы данных

Переменная

Переменная — это именованная область памяти для хранения данных.

Присваивание: name = value

Основные типы данных:

ТипНазваниеПример
intЦелое числоx = 5
floatВещественное числоy = 3.14
strСтрокаs = 'Привет'
boolЛогическийb = True

Ввод и вывод

Вывод: print(выражение)

Ввод: input(подсказка) — всегда возвращает строку.

Преобразование типов: int(), float(), str()

💻 Интерактивный пример

name = input('Как тебя зовут? ')
print('Привет, ', name)
