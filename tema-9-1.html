Одномерные массивы

Массив — это структура данных, хранящая набор элементов одного типа.

В Python массив реализуется с помощью списка (list).

# Создание массива
a = [1, 2, 3, 4, 5]

# Доступ к элементам
print(a[0])   # 1 (первый элемент)
print(a[-1])  # 5 (последний элемент)

# Длина массива
n = len(a)    # 5

Способы создания массива:

# Пустой массив
a = []

# Массив из N нулей
n = 10
a = [0] * n

# Заполнение с клавиатуры
a = [int(x) for x in input().split()]

# Ввод N чисел
n = int(input())
a = []
for i in range(n):
    a.append(int(input()))

Операции с массивами

a = [3, 1, 4, 1, 5]

# Перебор элементов
for x in a:
    print(x)

# Перебор с индексами
for i in range(len(a)):
    print(a[i])

# Сумма элементов
s = sum(a)

# Максимум / минимум
mx = max(a)
mn = min(a)

# Добавление элемента
a.append(9)

# Удаление по индексу
a.pop(2)

Поиск и сортировка

Линейный поиск:

a = [3, 1, 4, 1, 5, 9, 2, 6]
x = 5
found = False
for i in range(len(a)):
    if a[i] == x:
        print(f'Найден на позиции {i}')
        found = True
        break

Сортировка:

a = [3, 1, 4, 1, 5, 9, 2, 6]

# По возрастанию
a.sort()

# По убыванию
a.sort(reverse=True)

Пузырьковая сортировка — простейший алгоритм сортировки (O(n²)).

for i in range(len(a)):
    for j in range(len(a)-1-i):
        if a[j] > a[j+1]:
            a[j], a[j+1] = a[j+1], a[j]

Обработка строк

Строка — это последовательность символов. В Python строки неизменяемы.

s = "Привет, мир!"

# Длина строки
print(len(s))

# Доступ по индексу
print(s[0])     # П
print(s[-1])    # !

# Срез строки
print(s[0:6])   # Привет

# Поиск подстроки
print(s.find("мир"))    # 8

# Замена
print(s.replace("мир", "Python"))

Полезные методы строк:

s.lower()Нижний регистр
s.strip()Удаление пробелов
s.split()Разделение на части
