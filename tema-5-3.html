Ветвление (if-elif-else)

Условный оператор if

if условие:
    действие_1
else:
    действие_2

Пример:

x = int(input('Введите число: '))
if x > 0:
    print('Положительное')
elif x < 0:
    print('Отрицательное')
else:
    print('Ноль')

Логические операторы:

ОператорОписание
andИ (оба условия истинны)
orИЛИ (хотя бы одно истинно)
notНЕ (отрицание)

Цикл for (со счётчиком)

Цикл for

Используется, когда известно количество повторений.

for i in range(N):
    print(i)

Функция range():

ВызовРезультат
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9

Цикл while (с условием)

Цикл while

Выполняется, пока условие истинно.

i = 1
while i <= 5:
    print(i)
    i += 1
Внимание: Убедитесь, что условие цикла когда-нибудь станет ложным, иначе возникнет бесконечный цикл!

Практические задачи

🧪 Тренажёр алгоритмических конструкций

Мысленно выполните алгоритм:

s = 0
for i in range(1, 6):
    s = s + i
print(s)

Чему равно s?

s = 15 (сумма чисел от 1 до 5)
